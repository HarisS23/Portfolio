Overview

Flair is a full-stack social media web application built with ASP.NET Core and Angular. It gives users a space to share posts, interact with content, and build connections with others through follows and friend requests.

The goal was to build something that felt like a real platform, not just a CRUD app. Features like live notifications and online presence indicators, both using SignalR, give Flair the real-time responsiveness you'd expect from a modern social app.

Built as a university project with a focus on clean architecture and practical full-stack experience. It covers everything from JWT authentication and REST API design on the backend, to a responsive Angular frontend consuming it all.

Key Features

01

Post Management

Full create, edit, and delete control over posts. Users own their content and can update or remove it at any time.

02

Content Interaction

Likes and comments let users engage with content directly.

03

Connections

Users can send friend requests or follow others to build their network. The feed adapts to show content from their connections.

04

Live Notifications

Powered by SignalR, notifications are pushed instantly when someone likes, comments, or connects. No refresh needed.

05

Online Presence

Active status indicators show which users are currently online, giving the platform a real-time, connected feel.

06

User Search

Search lets users find others by name or username quickly, making discovery and connecting straightforward.

07

Explore

An explore page surfaces content beyond a user's immediate network, helping them discover new posts and people on the platform.
